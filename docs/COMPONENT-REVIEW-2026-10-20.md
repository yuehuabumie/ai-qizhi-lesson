# 前端排版与组件复查（2026-10-20 第二轮）

本轮接续全站手机适配，重点检查实际排版与组件的选择、加载、禁用、错误、键盘和弹窗状态。四个运行时模块的最终更新于 **2026-10-20 20:45:08（Asia/Shanghai）** 部署到生产，42 项组件、生产全站、窄屏及动态细节复核均已通过。本轮没有更换品牌视觉、改动后端接口或数据库结构。

## 发现与修复

- 页面画布：实际浏览器测得 `body` 保留默认 `margin:8px`，使导航和首页横幅四周多出空隙。明确设为 `0`，页面内容仍使用各自容器的内边距。
- 表单对齐：个人作品弹窗的输入框、文本框使用 `width:100%`，但原有盒模型还会额外增加边框与内边距，右侧贴到弹窗边缘。个人页及展厅控件明确采用 `border-box`；个人作品弹窗另有字段内侧对齐断言。
- 平板触控：账户菜单按钮原高 40px，手机、平板和粗指针设备下统一至少 44px。
- 主导航：“班级管理”由运行时注入，没有 Vue 编译生成的作用域属性，原有导航 CSS 无法匹配，出现浏览器默认的紫色下划线。补充仅作用于该入口的普通、悬停、选中、深色及键盘焦点样式；桌面和抽屉均适用。
- 作品图片：展厅详情及绘本正文图片由 `cover` 改为 `contain`，完整展示竖图和长图；封面缩略图继续使用 `cover`。保留原有容器比例及背景。
- 作品信息：`createdAt` 标签改为“创建时间”，避免将草稿和创建日期标成发布时间；展厅说明明确作品先存入“我的作品”，发布后才展示。
- 发布挑选：把复选框事件监听移到共同父容器，使“全选”、单项取消、半选、计数与提交按钮同步；没有草稿时隐藏选择栏。
- 发布状态：发布期间锁定选框和提交按钮，保留“发布中…”及 `aria-busy`；失败后恢复操作，防止再次点击开启并发批次。
- 个人作品筛选：补全 `tab` / `tabpanel` 关联，支持左右方向键循环与 Home/End，并同步选中状态和焦点。
- 个人页与展厅弹窗：保存并恢复原有背景 `inert`、滚动状态和焦点，支持 Tab/Shift+Tab 循环、Escape 关闭；资料/作品重绘后恢复到相应操作入口。
- 异步竞态：旧确认、旧保存、旧作品读取或旧发布完成时，不会关闭之后新打开的弹窗。
