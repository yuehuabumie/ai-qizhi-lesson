## 源码职责

`scripts/prep-studio.js` 只负责防重复启动和调用初始化。源码按职责拆到 `scripts/prep/`：

- `studio.js`：实例内页面状态、会话、上传、轮询、教师操作和 Vue 路由接入；保留前一轮的草稿与跨会话回调修复。
- `api.js`：统一请求前缀、JSON/二进制请求体、同源凭据和错误状态。
- `conversation.js`：纯数据的消息轮次、事件、提案和生成文件归组。
- `modals.js`：原生弹窗栈、可访问名称、关闭操作与焦点恢复。
- `sandbox.js`：互动 HTML 的双层不透明 iframe 和资源策略。
- `teaching-hub.js`：三入口、选中态、DOM 观察器及安装/释放生命周期；重复安装不会增加观察器，释放会取消监听与待执行帧。
- `presentation.js`、`icons.js`、`templates.js`：转义、显示文案、SVG 与页面模板。
- `styles.css`、`styles.js`：可独立编辑的 CSS，以及样式的幂等安装。

JavaScript 控制流程与 CSS 展开为多行，保留中文源码。主页面使用明确的 `state` 状态对象；请求上下文隔离逻辑不变。现有页面编排与部分 HTML 模板仍有较长函数，这是后续继续拆分的边界，并非完整 Vue 源码恢复。
