# 智能备课使用说明

本文面向教师，介绍智能备课的操作方式。管理员启用模型和隔离运行环境后，所有登录账号均可使用。

## 进入智能备课

使用本站现有账号登录，在顶部导航选择「智能备课」。手机上可先打开导航菜单，再选择该入口。当前面向所有登录账号开放，无需教师自行填写 API Key。

电脑界面分为对话列表、备课聊天和「过程与文件」三部分。手机上通过「对话」「备课」「过程与文件」标签切换。右上方「我的班级」可进入班级管理。

如果页面提示尚未启用或运行环境不可用，请联系管理员完成配置；发送和上传按钮会按实际可用状态开放。

## 开始并继续一段对话

点击「新建对话」，输入学科、年级、课题、课时和希望得到的成果，也可以先上传材料。信息尚不确定时，可以直接请 AI 先与你确认需求。

例如：

> 我准备给五年级上两课时的人工智能入门课。请先和我确认教学目标，再设计活动、评价方式和课堂练习。

点击「发送」，电脑也可按 Ctrl + Enter（Mac 为 Command + Enter）发送。AI 正在处理本次需求时，请等待完成或先停止任务，再继续发送。

对话历史会保存。刷新页面或以后重新打开同一对话，可以继续讨论其中的材料和结果。「新建对话」从独立上下文开始，不会自动读取其他对话的聊天或附件。个人 Skills 是账号的技能设置，与旧对话记忆分开管理。

对话标题旁的编辑按钮可重命名，方便以后查找。

## 添加图片与文件

- 手机：点击输入框旁的附件按钮，从相册或文件中选择材料；系统文件选择器提供拍照入口时，也可拍照上传。
- 电脑：点击附件按钮选择文件，或将图片、文件拖入备课页面。剪贴板提供图片或文件数据时，也可直接粘贴；普通文字照常输入或粘贴。
- 等待附件显示上传完成，再发送需求。失败的附件可点击重试，或移除后重新选择。

当前可上传的常见材料包括照片、截图、PDF（含扫描件）、Word（DOC/DOCX）、Excel（XLS/XLSX）、PPT（PPT/PPTX）、CSV、TXT 和 Markdown。图片支持 JPG、PNG、WebP、HEIC/HEIF。具体识别与转换能力取决于管理员启用的运行环境。

暂不支持 ZIP、RAR、7Z 等压缩包，请先解压并直接上传其中的文档或图片。手写或模糊材料会尽力识别；不能确认的信息需要补充清晰原件或由你核对，不应当作已正确识别。

可在同一条消息中附上多份材料，并说明它们各自的用途，例如「第一份是教材，第二份是班级名单」。单文件大小、附件数量、文件空间和任务额度，以页面提示及管理员配置为准。

## 查看执行过程和成果

打开「过程与文件」，可以查看排队、运行、等待确认、完成、失败或停止状态。展开「思考过程」可查看模型实际返回的推理内容；展开工具记录可查看调用内容和工具返回。模型没有返回的推理不会补写，普通状态提示也不等同于模型推理。

可以提出教案、课件、试卷、讲义、配图或互动网页等需求，说明希望的格式。以实际生成并出现在「生成文件」中的附件为准，点击文件可下载；AI 的文字回复不代表文件已经生成成功。

HTML 互动网页旁有「预览」按钮，可在站内打开安全预览并操作网页内的互动控件。预览仅运行自包含 HTML，外部图片、脚本、样式和联网访问受到限制，也不能读取本站页面或登录信息。因此依赖外部资源的网页可能显示不完整，可请 AI 改成自包含版本。超过在线预览限制或加载失败时，可按页面提示下载文件。

如状态暂未同步，可使用「执行过程」旁的刷新按钮，或重新打开对话查看。错误和失败会保留提示，可根据提示调整需求后再尝试。

## 核对后再修改班级和作业

创建班级、编辑名单、保存分组、创建或发布作业等业务变更，会先出现在「过程与文件」中的待确认卡片里。

1. 点击「查看完整预览」，核对班级、学生、题目和变更内容。
2. 需要调整时点击「编辑」，修改后选择「保存并重新预览」。重新核对更新后的内容。
3. 确定无误后点击「确认执行」。不需要该操作时点击「暂不执行」。

只有显示「已执行」，才表示该项变更已经应用。预览更新或失效时，需要重新核对最新内容，不能继续确认旧版本。你也可以在聊天中说明修改要求，让 AI 重新整理。

### 从名单创建班级或更新学生

「创建班级」用于建立新班级；「编辑班级名单」用于对已有班级增补、修改或删除学生。请说明目标班级和操作范围，并在预览中逐项核对，尤其是删除项。

例如：

> 请从这份文件整理三年级二班名单，保留姓名、学号、性别和成绩。缺失字段留空，不确定的地方列出来，先给我预览，再创建班级。

姓名必填，学号、性别和成绩均可不填。没有提供的内容不应补造；学号按文本保存，开头的 0 需要保留，成绩 0 也属于有效成绩。同一班级有同名学生时，须补充各自不同的学号，学生进入作业时使用姓名和学号区分。

你也可进入「我的班级」手动编辑学生资料，或在导入区粘贴姓名、学号、性别、成绩组成的表格。

### 保存和调整分组

可让 AI 提出分组方案，确认后保存到班级；也可在班级的「班级分组」区域创建或调整分组。支持随机分组，以及参考已提供性别或成绩的均衡分配，保存前可以逐人调整。

每名学生应恰好属于一个小组，缺失的性别或成绩不会补造。保存分组只更新班级小组，作业仍由每位学生分别完成和提交。

### 创建和发布试卷

试卷支持单选题和判断题，不包含多选题。可以让 AI 根据知识点、题量和难度拟题，或在班级中新建「试卷」作业，编辑题干、选项、分值、标准答案和可选解析。

核对预览后，可保存草稿或确认发布。草稿可继续编辑；发布后题目和答案不能再修改。发布后把作业链接发给学生。

学生填写姓名，必要时补充学号，在线作答并确认交卷。每人只能提交一次，交卷后不能修改、重做或重置。未公布结果时，提交页显示「已提交」，不展示得分、标准答案或解析。

教师在试卷管理页分别点击「公布成绩」和「公布答案解析」。这两项互不替代；仅完成对应公布操作后，已提交的学生才能在原作业链接刷新查看相应内容。关闭试卷后，未提交学生不能开始作答，已提交学生仍可核名查看已公布结果。试卷不发布到成果展厅。

## 使用个人 Skills

在对话列表下方打开「我的 Skills」，填写技能名称，粘贴技能说明，或选择一份 SKILL.md / TXT 文本，再点击「保存技能」。例如，可写入常用教案结构、课堂评价要求或教学活动设计方法。

Skills 仅属于当前账号，可在这里删除。当前上传的是文本技能说明，不是压缩包、完整插件或本地程序。MCP 工具由管理员配置，教师需要新增外部工具时请联系管理员。

## 后台任务、停止和删除

发送成功并进入队列后，即使关闭网页，任务仍会在服务器后台继续；重新登录并打开原对话可查看真实状态和结果。尚未发送的文字、未完成的上传不属于已开始的任务，离开前请确认发送成功。

要中止排队或执行中的任务，点击「停止」，等待状态更新为「已停止」。停止不会撤销此前已经确认执行的班级或作业变更。

删除对话前，请先停止正在进行的任务，并等待停止完成。点击对话标题旁的删除按钮并确认后，对话历史、上传附件和生成文件会一起清理；需要保留的文件请先下载。删除对话也不会撤销已经创建的班级、保存的分组或发布的作业，这些内容可在班级管理中查看。

首期不提供定时或周期任务。系统会根据管理员设置的并发与资源额度安排排队；如达到每日任务或空间限制，请按页面提示处理，或联系管理员。
