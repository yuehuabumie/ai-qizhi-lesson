## DeepSeek 官方真实调用

真实 Key 仅配置在 worker 的宿主私有文件，不进入代码、浏览器或执行容器。测试账号、班级和学生均为合成数据。

- 实际读取 CSV 和照片，合并四名学生，保留 001 等前导零、两名同名学生、缺失字段与 0 分；教师确认后创建班级。
- 同一会话继续读取真实成员编号、保存两组、修改一名学生成绩；每次写入均经过预览和确认。
- 创建并发布四题试卷（两道单选、两道判断），实际学生交卷后由服务端算出 100 分；重复提交被拒绝，未公布时不返回分数、答案和解析。
- Agent 分别申请公布成绩、公布答案；确认后实测学生接口先只显示成绩，后显示答案解析。
- 实际使用个人 Skill、计划/待办、子 Agent、联网搜索及 NASA 官方网页阅读；生成并交付两页中文 Word/PDF、四页 PPTX、教学配图和自包含 HTML 互动练习。
- Word/PDF 经实际渲染修复孤立标题；PPT 经 LibreOffice 打开并渲染四页。Office XML 检查器的外部 Dublin Core 元数据 XSD 获取存在环境限制，未将此项冒报为完整 XSD 通过。
- 真实生成的 HTML 在本站嵌套安全预览内通过额外 30 项交互检查（320/390px）：正确/错误反馈、计数、完成状态、重复点击保护、重新练习及内外层无横向溢出。
- 浏览器不持有任务请求，离开后可重新读取执行事件和结果。

首次多文件任务触及原有 40 次模型调用上限；现已改为管理员可配置的 PREP_MAX_MODEL_CALLS，默认 100，并保留明确错误。跨区链路曾使图片回传堵塞；仅对两服务器的对端路由启用 BBR，1.25MB 同一文件由约 24 秒降至约 1.4 秒，未更改全局拥塞配置。事件同步等待已放宽至 45 秒并保留故障重试。

## 运维与边界

主站负责账号、数据库、私有文件、队列和教师确认；独立 worker 使用受限 Docker 执行，单任务 1GiB、1.5 CPU，并发初始为 1。网站与 worker 使用受限 SSH 通道。

单文件硬上限 25MiB，管理员可调低；上传、历史、每日任务和排队额度独立限制。Nginx API 入口需允许 26MiB 请求。教师资料不进入公开展厅。删除对话还需成功清理其模型 Files、远端归档及本地附件。

普通文本、图片及常见 Office/PDF 有预装解析工具；手写、模糊、复杂排版不能保证正确，须由教师核对。未开放压缩包、定时任务、本地电脑控制和原版交互式 Plan 审批；计划采用待办与对话展示。管理员 MCP 初始为空，需配置审核过的远程服务；已验证协议链路不等于已连接任何具体第三方 MCP。
