# 智能备课 Agent：需求确认稿

状态：需求已确认，2026-10-21 开始实施。本文描述目标，不代表全部功能已通过验收。

## 已由用户确认

- 对所有已登录账号开放，接入网站现有账号；各教师的数据需要隔离。
- 模型采用 DeepSeek 官方 API 的 `deepseek-flash`，单独配置，不复用头像审核配置。
- 官方 API Key 由站点统一在服务端配置，教师不用分别提供密钥。
- 只保留当前对话的上下文，不建立跨对话的长期记忆。
- 对话历史持久保存，刷新或重新打开同一对话可继续；新对话不自动读取旧资料；删除对话时清理其附件。
- 支持文字对话、图片及文件输入；手机可上传，PC 可粘贴图片/文件及输入文字。
- 展示模型实际返回的推理内容，以及工具调用、执行进度和结果。推理展示来自模型返回，状态提示不能伪装成模型原始推理。
- 参考并保留 DSH 的联网检索/网页阅读、沙箱终端与 Python、文档生成、计划、子 Agent、Skills/MCP 等功能；沙箱允许联网，禁止操作用户本地电脑。
- 保留 DSH 的 agent 循环、系统提示词组装及工具机制，主要追加教学身份、网站业务规则和当前备课上下文，不另写一套缩减版聊天循环冒充完整 DSH。
- 创建班级、修改名单、发布作业等业务变更，先展示预览，用户确认后执行。
- 名单保存姓名、可选学号、可选性别和可选成绩；用户没有提供的字段可以留空，不能由模型补造。
- 分组结果保存到班级，作业仍由每位学生分别提交，不做小组共交一份。
- 新增试卷作业：单选题和判断题，不含多选；在线作答、自动判分；交卷后不立即展示答案解析，不允许重做。
- 学生提交试卷后只显示“已提交”；成绩与答案解析均由教师主动公布。
- 新增沿用本站风格的“智能备课”页面，兼顾手机和桌面布局。
- 关闭网页后，已开始的任务继续运行；首期不做定时或周期触发。
- 教师可上传自己的 Skills；MCP 由管理员配置。
- 首期支持照片/截图、扫描 PDF、Word（含旧版）、Excel（含旧版）、CSV、TXT、PPT 等常见格式。手写内容尽力识别，不确定处需教师确认；暂不支持压缩包。

用户回复“这个未知，对”，当前按以下理解推进：学段和学科暂不固定，由 Agent 在每次备课时向教师确认；Word/PDF 教案、PPT 课件、试卷讲义、配图和互动网页均纳入成果范围。

## 班级工具的作用

“创建班级”接收 AI 从资料中整理出的结构化候选班名和学生名单，校验后创建新班级。

“编辑班级名单”对已有班级追加、修改、删除或合并学生，预览中明确展示变更及受影响的提交记录；不能直接把模型识别结果当成整班覆盖操作。

文件解析和业务写入分开：读取原件 → 提取候选数据 → 标出重复、缺失和识别不确定项 → 展示可编辑预览 → 教师确认 → 服务端鉴权和校验后执行。相同姓名不能被自动当成同一个学生。

## 当前项目的实际约束

- 网站没有独立的教师角色或教师审核；任何注册账号均可建班。本轮已确认智能备课也面向所有登录账号开放，使用站点统一的官方 API Key。
- 名单当前只有姓名且班内唯一，学生凭作业链接和姓名进入。同名学生的验证方式需要与新增学号一起设计。
- 目前每账号最多 20 个班、每班 100 人及 50 份作业；是否调整额度应与实际需求核对。
- 现有作业仅 `storybook`、`lab`、`task`，创建即开放；没有试卷题目、标准答案、分组或作业草稿模型。
- 删除学生会影响其已有提交，已发布展厅的提交另有删除保护，新增工具须保留这些业务约束。
- 现有上传面向公开的作品图片，不是私有名册附件；通用文件、对话和生成物需要独立的鉴权存储。
- 仓库是后端源码、编译后的 Vue 网站及运行时模块，不含完整 Vue/Vite 源码。

## 核心验收目标

- 用两个独立账号核对会话、上传原件、生成文件、Skills、班级和工具权限；越权请求必须由服务端拒绝。
- 图片、文档与文本混合输入可发送，手机选择/拍照上传、桌面粘贴/拖放/选择文件有清晰的上传、失败和重试状态。
- 同一对话可追问材料内容，重复打开会话与新建会话的行为依据最终确认的保存规则验证。
- 从真实表格、文档、扫描件和手写样本解析名单；排除表头、合计及空行，保留学号前导零，缺失字段留空，重复或模糊项必须出现在预览中。
- 业务工具先提供可编辑预览，再执行确认过的同一份内容；过期预览、重复确认、未确认的直接调用不能造成重复或意外变更。
- 分组结果保存后可在班级中查看和调整；分组不改变原有的个人提交方式。
- 试卷仅单选/判断，标准答案不随未获授权的学生请求下发；得分由服务端计算；并发提交或重复请求不能绕过只交一次的限制。
- 展示实际的模型推理与工具事件，包含排队、运行、等待确认、成功、失败和取消，不把定时播放的文案当作执行记录。
- 关闭页面后任务继续；重开页面能够看到实际状态和完成产物。错误或中断不能被显示为成功。
- Word/PDF、PPT、试卷讲义、配图和互动网页产物须可实际打开或预览；生成的网页与上传内容使用受限制的预览环境。
- 在手机横竖屏、窄屏、平板和桌面核对对话、附件、工具卡、预览确认和错误状态，保留当前网站其余路由的回归检查。
